# Reflo

**One workspace for your coding agents and your source control.**

Reflo is a desktop app for people who work alongside AI coding agents. It keeps your repositories, worktrees, agent sessions, terminals and editor in one window, so you can see what your agents changed and act on it without switching between tools. Every git action shows the command it ran.

## Download

Get the latest build from [Releases](https://github.com/t2d-ev/reflo-releases/releases/latest):

- **macOS** (Apple Silicon): `Reflo_<version>_aarch64.dmg`
- **Windows** (x64): `Reflo_<version>_x64-setup.exe`

Once installed, Reflo checks for updates on launch and installs them from About Reflo.

This repository holds release builds only.
